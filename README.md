# 图书PDF提取工具

从图书PDF中提取文字和图片，输出 `txt/` + `img/` + `目录.xlsx` 文件包。

支持**任意尺寸、任意字号的PDF**，所有参数自动适配。

## 功能特性

- **自适应配置**：自动检测页面尺寸、正文字号，无需手动调参
- **文字提取**：精确识别PDF中的文字内容，过滤页眉、页脚、页码
- **图片提取**：截取PDF中的图片，自动合并OCR碎片，过滤装饰性小图
- **图片文字页检测**：页面大部分为图片中文字时，整页截为图片不提取文字
- **目录生成**：自动生成三级层级结构（书名→章→节）的Excel目录
- **章标题提取**：从页脚提取章标题，模糊匹配处理OCR变异
- **书名自动识别**：从页脚频率统计自动提取书名，无需硬编码
- **OCR噪声过滤**：过滤嵌入汉字间的短ASCII噪声、孤立符号等

## 硬约束

1. **不提取**页眉、页脚、页码（横向纵向都不提取）
2. 表格/图表/统计图 → **截取为图片**，不把其中内容当文字提取
3. **文字精确识别**：txt中不得出现代码/乱码/错乱；图片中含文字则整张截为图片
4. **目录三级结构**（章/节/目）：只有章→节=目=章；有章+节无目→目=节

## 安装依赖

```bash
pip install pymupdf openpyxl Pillow
```

## 用法

```bash
# 基本用法（输出目录默认为PDF文件名，自动适配所有参数）
python extract_book.py book.pdf

# 指定输出目录
python extract_book.py book.pdf 输出目录

# 传递额外特殊标题（逗号分隔，如丛书编委会、大事年表等）
python extract_book.py NH0633.pdf 柔石画传 "龙华英烈画传系列丛书编委会,柔石大事年表"
```

## 自适应配置

脚本运行时自动检测以下参数，无需手动设置：

| 参数 | 自适应方式 | 说明 |
|------|-----------|------|
| 页面尺寸 | `page.rect.width/height` | 从PDF第一页获取 |
| 正文字号 | 字号频率统计 | 采样前50页，取出现频率最高的字号 |
| 页脚阈值 | `page_h × 0.90` | 页面高度90%位置 |
| 页眉阈值 | `page_h × 0.07` | 页面高度7%位置 |
| 节标题字号 | `body_sz + 2` | 正文字号+2 |
| 噪声字号 | `body_sz × 0.55` | 正文字号的55% |
| 图片文字页阈值 | `body_sz × 0.82` | 正文字号的82% |
| 图片说明字号 | `body_sz × 0.78` | 正文字号的78% |
| 图片最小面积 | `page_w × page_h × 0.01` | 页面面积的1% |
| 书名 | 页脚频率统计 | 出现在≥20%页面的标签 |

运行时会打印检测结果：
```
PDF自适应: 页面1937×2820, 正文字号47
  页脚阈值=2538, 节标题字号≥49, 噪声字号<26
```

## 输出格式

### txt/ 目录

- UTF-8编码文本文件
- 文件名：`XXXX.txt`（XXXX为4位节编号，如 `0001.txt`）
- 首行为节标题，空行分隔段落
- 图片占位符独占一行：`<img>img/XXXX_N.png</img>`

### img/ 目录

- PNG格式图片
- 文件名：`XXXX_N.png`（XXXX为4位节编号，N为节内图片序号）
- 自动过滤全页背景图、装饰性小图、OCR碎片

### 目录.xlsx

4列结构：

| 列名 | 说明 |
|------|------|
| 序号 | 行号 |
| 目录名 | 书名/章标题/节标题 |
| 层级 | 1=书名, 2=章/特殊标题, 3=节 |
| 整理后TXT | 对应的txt文件编号（仅层级3有值） |

层级结构示例：

```
1  柔石画传                              1
2  柔石画传                              2
3  龙华英烈画传系列丛书编委会            3  → 0001
4  出版说明                              3  → 0002
5  目录                                  2
6  目录                                  3  → 0003
7  一 负笈异乡跳出大山包围              2
8  降生：在孔子的诞辰                   3  → 0004
   ...
54 柔石大事年表                          2
55 柔石大事年表                          3  → 0043
56 参考文献                              2
57 参考文献                              3  → 0044
58 后记                                  2
59 后记                                  3  → 0045
```

## 技术细节

### 章标题和书名提取

均从**页脚**提取（而非章扉页OCR），因为页脚OCR质量更稳定：

- 奇数页页脚格式：`{章标题}{页码}`
- 偶数页页脚格式：`{页码}{书名}`

提取流程：

1. 遍历所有页，提取页脚文字（y > 页脚阈值）
2. 去除页码数字、噪声符号
3. 统计标签出现频率，**自动识别书名**（出现在≥20%页面的标签）
4. 排除书名页后，其余 → 章标题候选
5. 模糊聚类归一化（`SequenceMatcher` 相似度 > 0.7）
6. 过滤噪声（中文字符占比 < 50%、匹配特殊标题、含URL/价格、出现页数 < 3）
7. 按首次出现顺序分配中文数字前缀（一、二、三...）

### 节标题检测

- 含中文冒号"："
- 字号 ≥ 正文字号+2
- 宽度 < 页面宽度×0.52
- 长度 4-30
- 非数字开头
- 中文字符占比 > 60%
- 不以句号/感叹号/引号+句号结尾
- 冒号前缀 1-8 字，不含逗号
- 排除含"编委"、前缀含"》"但不含"《"等

### 特殊标题分类

通用特殊标题（自动识别）：
- 前置：出版说明、前言、序言、序
- 后置：后记、附录、参考文献、大事年表

根据**页码位置**自动分类：
- 在所有章之前 → 前置（层级3，在书名层级2下）
- 在所有章之后 → 后置（层级2+3）

可通过命令行第3个参数传递额外特殊标题（如丛书编委会名称）。

### 图片文字页检测

当页面大部分文字字号远小于正文时，整页截为图片：

- 字号 ≥ 正文字号×0.82 的文字占比 < 20% → 判定为图片文字页

### OCR噪声过滤

三级过滤：

1. 字号 < 正文字号×0.55 的文字块
2. 纯短ASCII块（≤3字符）
3. 正则去除汉字间嵌入的短ASCII（如"缺 Ml乏"→"缺乏"）
