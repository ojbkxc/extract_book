# 图书PDF提取工具

从图书PDF中提取文字和图片，输出 `txt/` + `img/` + `目录.xlsx` 文件包。

## 功能特性

- **文字提取**：精确识别PDF中的文字内容，过滤页眉、页脚、页码
- **图片提取**：截取PDF中的图片，自动合并OCR碎片，过滤装饰性小图
- **图片文字页检测**：页面大部分为图片中文字时，整页截为图片不提取文字
- **目录生成**：自动生成三级层级结构（书名→章→节）的Excel目录
- **章标题提取**：从页脚提取章标题，模糊匹配处理OCR变异
- **OCR噪声过滤**：过滤嵌入汉字间的短ASCII噪声、孤立符号等

## 硬约束

1. **不提取**页眉、页脚、页码（横向纵向都不提取）
2. 表格/图表/统计图 → **截取为图片**，不把其中内容当文字提取
3. **文字精确识别**：txt中不得出现代码/乱码/错乱；图片中含文字则整张截为图片
4. **目录三级结构**（章/节/目）：只有章→节=目=章；有章+节无目→目=节

```bash

```

## 输出格式

### txt/ 目录

- UTF-8编码文本文件
- 文件名：`XXXX.txt`（XXXX为4位节编号，如 `0001.txt`）
- 首行为节标题，空行分隔段落
- 图片占位符独占一行：`<img>img/XXXX_N.png</img>`

### img/ 目录

- PNG格式图片
- 文件名：`XXXX_N.png`（XXXX为4位节编号，N为节内图片序号）
- 自动过滤全页背景图、装饰性小图、OCR碎片

### 目录.xlsx

4列结构：

| 列名 | 说明 |
|------|------|
| 序号 | 行号 |
| 目录名 | 书名/章标题/节标题 |
| 层级 | 1=书名, 2=章/特殊标题, 3=节 |
| 整理后TXT | 对应的txt文件编号（仅层级3有值） |

层级结构示例：

## 技术细节

### 章标题提取

章标题从**页脚**提取（而非章扉页OCR），因为：

- 奇数页页脚格式：`{章标题}{页码}`
- 偶数页页脚格式：`{页码}{书名}`

提取流程：

1. 遍历所有页，提取页脚文字（y > 2540）
2. 去除页码数字、噪声符号
3. 含书名"柔石画传"的页 → 提取书名
4. 其余页 → 章标题候选
5. 模糊聚类归一化（`SequenceMatcher` 相似度 > 0.7）
6. 过滤噪声（中文字符占比 < 50%、匹配特殊标题、含URL/价格、出现页数 < 3）
7. 按首次出现顺序分配中文数字前缀（一、二、三...）

### 节标题检测

节标题检测规则（已验证100%命中）：

- 含中文冒号"："
- 字号 > 49
- 宽度 < 1000
- 长度 4-30
- 非数字开头
- 中文字符占比 > 60%
- 不以句号/感叹号结尾
- 冒号前缀 1-8 字
- 排除含"编委"、前缀含"》"但不含"《"等

### 图片文字页检测

当页面大部分文字字号远小于正文时（正文46-50，图片中文字<32），整页截为图片：

- 字号 ≥ 40 的文字占比 < 20% → 判定为图片文字页

### OCR噪声过滤

三级过滤：

1. 字号 < 28 的文字块
2. 纯短ASCII块（≤3字符）
3. 正则去除汉字间嵌入的短ASCII（如"缺 Ml乏"→"缺乏"）

## 配置参数

关键参数定义在脚本顶部，基于 NH0633.pdf 探索结果：

| 参数 | 值 | 说明 |
|------|-----|------|
| `FOOT_Y_THRESHOLD` | 2540 | 页脚y坐标阈值 |
| `HEAD_Y_THRESHOLD` | 200 | 页眉y坐标阈值 |
| `SECTION_MIN_SZ` | 49 | 节标题最小字号 |
| `IMG_MIN_AREA` | 50000 | 图片最小面积 |
| `NOISE_MIN_SZ` | 28 | 文字最小字号（低于此为噪声） |
| `IMG_TEXT_BIG_SZ` | 40 | 正文文字字号阈值 |
| `IMG_TEXT_BIG_RATIO` | 0.2 | 正文文字占比阈值 |
